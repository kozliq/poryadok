# Порядок

Раскладывает Рабочий стол, Загрузки и Документы по полкам: скриншоты к скриншотам, договоры к договорам, установщики в «На удаление». Работает на Маке и Windows. Бесплатная, с открытым кодом, без регистрации и без интернета.

Три обещания, которые программа не нарушает:

1. **Ничего не удаляет.** Только переносит. Мусор, дубли и пустые файлы складывает в папку «На удаление» на Рабочем столе, а удаляете их вы сами.
2. **Ничего не перезаписывает.** Если имя занято, файл получит имя `фото (2).jpg`.
3. **Всё можно вернуть.** Каждый перенос записывается в журнал, кнопка «вернуть прошлую» возвращает всё на свои места.

## Как это выглядит

Окно в виде визитки: цвет кости, шрифт EB Garamond, кнопки сделаны текстом. Размер окна рассчитывается по экрану (см. ниже).

1. Выберите папку («Рабочий стол», «Загрузки», «Документы», «Всё сразу») или перетащите любую папку на окно.
2. Программа покажет план: куда поедет каждая вещь и **почему**: «в названии «договор»», «в тексте «акт выполненных работ»», «формат .pdf», «точная копия, байт в байт».
3. Если план устраивает, нажмите «Разложить». Если передумали, нажмите «вернуть как было».

## Установка

Скачайте файл для своей системы со страницы [Releases](../../releases):

| Система | Файл |
|---|---|
| Мак на M1–M4 | `Порядок_*_aarch64.dmg` |
| Мак на Intel | `Порядок_*_x64.dmg` |
| Windows 10/11 | `Порядок_*_x64-setup.exe` |

Программа не подписана платным сертификатом Apple или Microsoft: сертификат стоит денег, а программа бесплатная. Поэтому при первом запуске система предупредит:

- **Мак:** правый клик по «Порядку» → «Открыть» → «Открыть». Если не помогло: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
- **Windows:** в синем окне SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

Чтобы раскладывать Рабочий стол и Документы, Маку нужно разрешение. Он спросит его сам при первом плане.

## Как программа решает, куда что

Для каждого файла решение принимается в три ступени, от точного признака к общему:

1. **Слово в названии.** «Договор_аренды.pdf» → Договоры и счета. Слово ищется с начала слова («скан» не найдётся в «москанал»), без русского окончания («смета» найдёт «сметы») и латиницей («dogovor», «schet», `DogovorArendy`).
2. **Фраза в тексте.** Если название ничего не говорит («Документ1.pdf»), программа читает начало текста: PDF, DOCX, ODT, RTF, TXT, а на картинках распознаёт текст встроенным в систему движком (Vision на Маке, Windows OCR). Нашлось «счёт на оплату», значит, это счёт.
3. **Расширение.** Всё прочее раскладывается по типу: картинки, видео, музыка, PDF, архивы.

Плюс несколько правил для любителей полного порядка:

- скриншоты и фото с телефона раскладываются по месяцам: `Скриншоты/2026-10`;
- «отчёт (1).pdf» и «отчёт копия.pdf» становятся «отчёт.pdf», если такое имя свободно;
- папка «1» или «Новая папка» с фото с телефона получает имя «С телефона 26.10.2026»;
- точные копии (сравнение байт в байт) и пустые файлы отправляются в «На удаление/Дубли» и «На удаление/Пустые»;
- папки целиком двигаются, только если вы разрешили («папки: двигаю целиком») и в папке не меньше 70 % файлов одного вида.

### Чего программа не трогает никогда

| Что | Как узнаёт |
|---|---|
| Папку, в которой сейчас работает программа (терминал, редактор, чат) | `lsof -a -d cwd` |
| Папку, куда система сохраняет скриншоты | `defaults read com.apple.screencapture location` |
| Папку, на которую ссылается скрипт или фоновая задача | ищет пути в скриптах на столе, в `~/Library/LaunchAgents`, `~/.local/bin` |
| Рабочую папку программы (например, `DragShift` при установленном `DragShift.app`) | имя папки = имя программы |
| Проекты с кодом | `.git`, `package.json`, `Cargo.toml`, `.vscode` и ещё 20 признаков |
| Ярлыки, программы, скрипты `.command` / `.bat` | тип файла |
| Файлы младше двух минут и недокачанные `.crdownload` / `.part` | время и расширение |
| Папку из одних скрытых файлов (данные программы) | содержимое |

Для каждой оставленной вещи в плане написано, почему она осталась на месте.

### Свои правила

Команда `poryadok правила` (или «свои правила» в окне) создаёт файл `rules.json` со стандартными полками. Его можно дополнить, например, полкой для клиента:

```json
{ "name": "Кафе «Монплезир»", "place": "documents", "path": "Клиенты/Монплезир", "keywords": ["монплезир"] }
```

Сюда попадут и «Меню Монплезира.pdf», и `monplezir_logo.png`: учитываются падежи и латиница.

## Облако

Если включены «Рабочий стол и Документы в iCloud», часть файлов лежит только в облаке. Программа их не читает, потому что иначе система скачала бы их. Перенос внутри iCloud (со стола в Документы) обходится без скачивания. При переносе наружу (в Фильмы или Изображения) файл скачается, и план заранее пишет, сколько это будет: «Из облака скачается 975 МБ».

## Приватность

- Всё работает на вашем компьютере. Программа не ходит в интернет: в коде нет ни одного сетевого запроса, а в окне это запрещено настройкой безопасности (CSP).
- Нет аккаунтов, аналитики и телеметрии.
- Текст файлов читается только для выбора полки и никуда не сохраняется. Если не хотите, чтобы программа читала файлы, используйте `poryadok план --только-имена`.
- Журналы переносов хранятся у вас: `~/Library/Application Support/poryadok/journal` на Маке, `%APPDATA%\poryadok\journal` на Windows. В них только пути.

## Ограничения

- Программа не понимает смысла так, как человек. Отличить «договор с клиентом» от «договора аренды квартиры» она не может: для этого есть свои правила.
- Распознавание текста на картинках зависит от системы. Если системный движок не отвечает, программа ждёт до 5 секунд и дальше решает по названиям.
- Папки с кодом не переносятся никогда: в них бывают абсолютные пути (виртуальные окружения, настройки IDE), и после переноса проект может сломаться.
- Если файл перенесли с другого диска, программа его не трогает: она только переименовывает и никогда не копирует.

## Устройство

```
диск ──► scan ──► Snapshot ──► plan ──► Plan ──► exec::apply ──► диск
           │                    ▲                     │
   lsof, скрипты,     правила, места, Disk       журнал (WAL)
   скриншоты, текст                                   │
                                     exec::undo ◄─────┘
```

- `core/` — ядро на Rust, общее для окна и командной строки.
  - `scan` — единственное место, которое читает диск перед планом. Собирает снимок: вещи, их тексты, защиты.
  - `plan` — решает, что куда. Диск не меняет. Всё, что ему нужно знать о диске, сводится к трём вопросам (`Disk`): занято ли имя, что лежит на полке, одинаковы ли два файла. Поэтому план детерминирован и легко проверяется.
  - `exec` — единственное место, которое меняет диск. Только `rename`, никаких «скопировать и удалить».
  - `journal` — журнал с упреждающей записью: сначала «собираюсь перенести», потом перенос, потом «перенёс», и каждая строка сразу сбрасывается на диск. Если выключить питание посреди раскладки, откат сам разберётся, что успело переехать.
  - `rules`, `content`, `ocr`, `platform` — правила, чтение текста, распознавание, различия Мака и Windows.
- `app/` — окно на Tauri 2. В нём только мост между интерфейсом и ядром.
- `ui/` — интерфейс: HTML, CSS и один JS-модуль, без сборщиков и библиотек. `ui/mock.js` позволяет править дизайн в обычном браузере без Rust.

### Размер окна

Окно сделано в пропорциях визитки 85 × 55 мм. Его ширина составляет малую долю золотого сечения рабочей области экрана (W = S / φ² ≈ 38 %), высота не больше S / φ. По вертикали окно стоит в оптическом центре: свободное место делится золотым сечением, сверху меньшая часть. Кегль текста равен ширине окна, делённой на 36, то есть не меньше 15 px. Формула и тесты для MacBook Air и Full HD с масштабом 125 % лежат в [`core/src/card.rs`](core/src/card.rs).

## Сборка

Нужны [Rust](https://rustup.rs) и Node.js (только для сборщика Tauri).

```bash
cargo test -p poryadok-core   # тесты ядра
npm install                   # сборщик окна
npm run dev                   # окно в режиме разработки
npm run build                 # установщик для своей системы
```

Командная строка без окна:

```bash
cargo run -p poryadok-core -- план всё          # план для стола, загрузок и документов
cargo run -p poryadok-core -- почему ~/Downloads/Документ1.pdf
cargo run -p poryadok-core -- разложить         # сначала спросит
cargo run -p poryadok-core -- вернуть
```

Новая версия собирается сама: `git tag v0.1.0 && git push --tags`. Через 15 минут на странице Releases появится черновик с установщиками для Windows и обоих видов Маков.

## Тесты

- **Ядро:** более 40 тестов. Среди них проверка на 150 случайных рабочих столах: после «разложить» ни один файл не потерян и не задавлен, а после «вернуть» дерево папок совпадает с исходным байт в байт. Есть имитация выключения питания посреди раскладки.
- **Эталон** (`core/tests/reference.jsonl`): 41 решение из ручной разборки настоящего Рабочего стола (имена проектов и клиентов заменены). Для каждого записано, чем смотрели, что заметили, куда положили и почему. Алгоритм совпадает с ручной разборкой во всех 25 общих случаях. Остальные 16 опирались на знание о проектах человека, и для них нужны свои правила.
